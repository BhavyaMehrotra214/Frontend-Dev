Responsive CSS Cheat Sheet

Filters

CSS filters modify image appearance — e.g., filter: grayscale(100%);, blur(5px);, or hue-rotate(90deg);.

Media Queries

Use media queries to adapt layouts. Example: @media (max-width: 600px) { ... } changes styles for small screens.

Responsive Design

Create layouts that adapt to screen size using units like %, vw, vh and flexible tools like flexbox or grid.

Typography

Use relative units and clamp() for scalable text. Example: font-size: clamp(1rem, 2vw, 2rem);.
